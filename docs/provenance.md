# Data Provenance & Lawful Use

- **All data is synthetic**, generated by `payequity` with a fixed seed (default `20261022`).
- No real employee, candidate or personal data is used, collected or redistributed.
- Names are pseudonyms (`Employee 000001`); `analysis_cohort` is a synthetic, audit-only label.
- Market base salaries, geo differentials and FX rates in `config/reference/` are **illustrative
  values chosen by the author** for realism; they are not copied from any licensed dataset.
